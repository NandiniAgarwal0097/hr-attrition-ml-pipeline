HR Attrition ML Pipeline

An educational, end-to-end employee attrition classification project using synthetic data, Pandas, scikit-learn and SMOTENC.

## Overview

This guided notebook demonstrates how to build and evaluate a simple machine-learning pipeline for a fictional HR retention scenario. It predicts whether a synthetic employee record is labeled as stayed (0) or resigned within the following year (1). The goal is to practise sound data preparation and evaluation—not to explain why a person leaves or make decisions about real employees.

All records are generated in the notebook. No real employee data or external CSV download is required.

## Dataset

The notebook creates 1,000 fictional employee records, introduces missing values in selected input columns, and appends 20 duplicate rows for cleaning practice. Features include experience, monthly salary in INR, satisfaction score, overtime, absences, department and work mode. `EmployeeID` is excluded from model inputs, and `Resigned` is the target.

## Workflow

1. Generate and load the synthetic dataset.
2. Inspect data types, missing values and duplicate rows.
3. Remove exact duplicates and check basic value ranges.
4. Define features and target, excluding the identifier.
5. Create a stratified 80/20 train/test split.
6. Explore training data and class balance.
7. Fit numerical and categorical imputers using training data only.
8. Scale numerical features and apply SMOTENC to training data only.
9. One-hot encode categorical features and train Logistic Regression models with and without oversampling.
10. Compare accuracy, precision, recall and F1 on the same untouched test set; inspect confusion matrices.
11. Interpret model coefficients and a fictional example prediction with appropriate caveats.
12. Save the cleaned dataset, comparison results and fitted preprocessing/model bundle.

## Requirements and setup

The first notebook cell installs pinned versions of the two less common dependencies:

- scikit-learn 1.7.2
- imbalanced-learn 0.14.0

The notebook also uses Python, Pandas, NumPy, Matplotlib and Joblib. Run it in Google Colab with a standard CPU runtime, or use a local Jupyter environment with compatible package versions. Open the `.ipynb` file and run cells from top to bottom. The dataset is generated automatically.

## Files generated by the notebook

- `hr_attrition_raw.csv` — generated data, including deliberate duplicates and missing input values.
- `hr_attrition_cleaned.csv` — deduplicated records.
- `model_comparison.csv` — observed held-out model metrics.
- `hr_attrition_teaching_model.joblib` — fitted imputers, scaler, encoder and classifier.

The notebook itself is `HR_Attrition_Monday_Complete_Pipeline.ipynb`.

## Limitations and responsible use

This is a teaching exercise built on synthetic data. Its metrics do not establish real-world predictive performance. The generated target comes from a simplified teaching formula and is not evidence about actual employee behavior. Model coefficients and feature associations do not establish causes. Scores may not be calibrated probabilities, particularly after oversampling.

Do not use this notebook or its model to make hiring, promotion, termination or other employment decisions. Any real-world study would require representative and lawfully handled data, rigorous validation, privacy safeguards, fairness assessment, human oversight and ongoing monitoring. Only load Joblib files from sources you trust.

## Learning outcomes

Practise data loading, cleaning, exploratory analysis, leakage-aware preprocessing, mixed-type class-imbalance handling, classification, evaluation and responsible interpretation.
